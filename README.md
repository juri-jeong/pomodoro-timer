# Pomodoro Timer

A pixel-style Pomodoro timer and task manager built with HTML, CSS, and JavaScript.

## Features

- Create and manage tasks
- Set focus time and session goals
- Start, pause, and reset the timer
- Work and break modes
- Track completed sessions
- Track total focus time
- Task progress bar
- Save tasks with Local Storage
- Completion sound notification
- English and Japanese task name support

## Tech Stack

- HTML
- CSS
- JavaScript
- Local Storage API

## How to Use

1. Enter a task name.
2. Set the focus time and session goal.
3. Click **Add Task**.
4. Select a task.
5. Click **Start** to begin the Pomodoro timer.
6. Use **Pause** or **Reset** when needed.
7. Switch to **Break** mode when you need a break.
8. Completed sessions are tracked automatically.
